Useful features:
- **VSCode Dev Containers**. It's docker container but fo developing. It has a preconfigured environment for your project. Keep the projects dependencies separate from your host machine
- **Add Folder to Workspace**: you can add multiple repos in the same workspace so you can do a global search on all of them instead of having one window open per repo
- **VS Code Live Share** is a feature that lets you collaborate on code in real time
