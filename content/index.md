Hey there, I'm Nacho. Welcome to my Digital Garden!

I started this website as an exercise to make public the thoughts, ideas and learnings I've been writing down in the last few years and gathering in a private space. The purpose of this page is to:
- Improve my writing and communication skills. Learn how to explain concepts in an engaging way, expecting an audience will read this
- Hopefully teach something new to whoever is reading this

This is not a collection of articles or posts that have been adequately written and that can't be modified. Here, I'll include notes and pages that are imperfect and that can change over time. Learning is an iterative process, and my intention is to document my learning as it happens, without the friction of having to write a properly structured article.

This is an "always work in progress" website. A mind map to check previous learnings and update new ones.

Some people also call this a Second Brain.
